换编码 Agent 时额度用完，会话还躺在磁盘上，只是换了个工具就找不到了。find-my-session 跨 21 个编码 Agent 的本地存储做关键词 / 目录 / 时间检索，并输出低 token 的接力摘要（任务、todo、最近改动、用户提示词）——贴给下一个 Agent 就能继续。 When a harness runs out of quota mid-task, the session still exists on disk — it just becomes unfindable from the next tool. find-my-session searches the local stores of 21 coding agents by keyword, directory, and time, then prints a low-token handoff digest (task, todos, recent edits, prompts) you paste into the next harness and continue.

01 — FLOW

三步，把断掉的活接上Three steps to pick up where you left off

先按关键词或目录找到会话，再打印接力摘要；额度恢复或换工具后，用 resume 跳回去。Find the session by keyword or directory, print the handoff digest, then jump back in with resume.

fms search → fms show
$ fms search "theme toggle" --harness qoder-cn
ref                 updated         cwd                       title
qoder-cn:b2c3d4e5   2026-10-27 23:30  /Users/example/project…   Add a dark mode toggle…

$ fms show qoder-cn:b2c3d4e5
# qoder-cn:b2c3d4e5
- harness: qoder-cn (desktop, cli)   - turns: 1
## Task
Add a dark mode toggle to settings
## Todos (1 open / 2 total)
- [pending] Verify contrast in light and dark themes
## Recent tools
- 22:00 Write: …/src/settings/ThemeToggle.tsx
STEP 1 · SEARCH

按记忆搜Search by memory

关键词、目录、时间任意组合；只输出元数据，不读全文。Keyword, cwd, and time filters; metadata-only output. fms latest --cwd .

STEP 2 · SHOW

拿接力摘要Take the digest

任务、todo、最近工具调用，而非整段 transcript，省 token。Task, todos, recent tools — not the whole transcript. fms show <ref>

STEP 3 · RESUME / PROMPTS

跳回 / 翻提示词Jump back / page prompts

能直跳的 harness 一键恢复；人类提示词可分页逐条看。One-key resume where supported; page every human prompt. fms prompts <ref> --limit 5

02 — TWO SHAPES

一个内核，两种形态One core, two shapes

给 Agent 用的 skill（fms 命令行）与给人看的本地浏览器面板（fms-ui），共享同一份核心。An agent skill (the fms CLI) and a human browser panel (fms-ui) sharing one core.

⌕ fms · agent skill

额度耗尽时，Agent 自己用它找回上下文：search 定位、show 交接、prompts 翻历史、doctor 自检存储健康。When quota runs out, the agent itself recovers context: search, hand off with show, page history, check stores with doctor.

fms search "oauth token refresh" --harness claude-code fms show claude-code:e1a2b3c4 fms resume claude-code:e1a2b3c4 --exec

◧ fms-ui · local panel

同一份数据的人类视图：关键词与元数据筛选、会话概览、分页的人类提示词、可复制引用。只绑 127.0.0.1。The human view of the same data: keyword and metadata filters, overviews, paged prompts, copyable refs. Binds 127.0.0.1 only.

fms-ui --no-browser --port 8765 # or: python3 fms_ui/fms-ui (from source)
fms search按关键词搜会话元数据；不给 query 则列最近会话。Search session metadata by keywords; empty query lists recent sessions. --harness --cwd --since
fms show打印低 token 接力摘要，并给出原始文件路径。Print the handoff digest plus the raw source path. --messages --chars
fms prompts只列人类提示词，可计数、分页、调序。Human prompts only, with count, paging, and ordering. --count --limit/--offset
fms resume在原 harness 里跳回该会话；不支持则退回摘要。Reopen the session in its harness; falls back to the digest. --exec
fms stats按 harness 聚合各家自己记录的 token / 费用。Aggregate the token/cost usage each harness records. --since 7d
fms doctor检查解码器、存储可读性；--fingerprint 只上报结构不含内容。Check decoders and store health; --fingerprint reports shape, never content.

04 — PRIVACY

先讲隐私，再讲功能Privacy first, features second

找会话的工具本身必须值得信任：三条硬约束写死在设计里。A session finder must itself be trustworthy: three hard constraints by design.

严格只读Strictly read-only

只读打开会话文件与 SQLite（mode=ro），永不写入、删除或修改任何存储。Session files and SQLite stores open read-only (mode=ro); nothing is ever written or deleted.

全本地运行Fully local

CLI 不发任何网络请求；面板只绑 127.0.0.1。架构变化上报用去内容的 fingerprint。The CLI makes no network requests; the panel binds 127.0.0.1. Drift reports use content-free fingerprints.

纯标准库Stdlib only

零第三方依赖，一个 pipx 包即装即用；供应链面最小。Zero third-party dependencies; minimal supply-chain surface.

05 — INSTALL

四种安装，按需取用Four ways to install

日常用 pipx；只跑一次就用 uvx；给 Agent 装 skill、给人看面板都有离线 ZIP。pipx for daily use, uvx for one-offs, offline ZIPs for the skill and the panel.

CLI + UI · pipx

pipx install find-my-session

同时装上 fms 与 fms-ui。升级用 pipx upgrade，卸载用 pipx uninstall。Installs both fms and fms-ui in one shot.

One-off · uvx

uvx --from find-my-session fms search "quota handoff"

不安装直接跑当次命令，适合临时找回。Run once without installing — good for a quick rescue.

Agent skill · ZIP

# releases/latest → find-my-session-skill.zip

解压后链到 harness 的 skills 目录（如 Qoder / Claude Code）。源码用户也可直接跑 skills/find-my-session/scripts/fms。Unzip and link into your harness skills folder. From source, run scripts/fms directly.

UI panel · ZIP

python3 fms-ui # in the extracted dir

下载 find-my-session-ui.zip，解压即用；源码用户跑 fms_ui/fms-ui。Download find-my-session-ui.zip and run; from source use fms_ui/fms-ui.

06 — FAQ

常见问题Questions, answered

完整版见文档 FAQ，这里只收最常被问到的五条。The full version lives in the docs FAQ; these are the top five.

我的会话内容会被上传吗？Is my session content uploaded anywhere?

不会。一切都在本地运行，CLI 零网络请求；面板只监听 127.0.0.1。注意 show / prompts 会打印对话原文，转贴时按原文对待即可。No. Everything runs locally with zero network requests; the panel binds 127.0.0.1 only. Note show/prompts print conversation text — treat reposts like the original transcript.

它会改我的会话文件吗？Will it modify my session files?

不会。所有存储都以只读方式打开（含 SQLite 的 mode=ro），search 输出甚至只有元数据。No. Every store opens read-only (SQLite via mode=ro), and search output is metadata-only.

搜不到我记得的会话？Search finds nothing I remember?

搜索是 AND 语义：先减一个关键词，去掉 --cwd / --since，再试一次 --include-archived（归档默认隐藏）。还不行就跑 fms doctor 看存储是否可读。Search is AND-only: drop a keyword, drop --cwd/--since, retry with --include-archived (archived hides by default). Then run fms doctor to check store readability.

Codex / DeepSeek 的压缩会话被跳过了？Compressed Codex/DeepSeek sessions skipped?

.jsonl.zst / .zstd 需要解码器：Python 3.14 自带，否则装 zstd 命令行；缺了会跳过并在 doctor 里报 decoder-missing。They need a zstd decoder: built into Python 3.14+, otherwise install the zstd CLI. Without it they are skipped and doctor reports decoder-missing.

Windows 能用吗？Does it work on Windows?

暂不正式支持：只有实验性、非阻塞的 CI 在跑。欢迎社区验证报告，路线见 ROADMAP。Not officially: only an experimental, non-blocking CI job. Community verification reports are welcome; see the roadmap.
